# 2026-02-28

## AI Calorie Tracking Feature

### Implemented

- **AIService vision support**: Extended `AIService` with `analyzeWithImage()` method for multimodal (image + text) requests. Uses the same OpenAI-compatible chat completions API with array-of-parts content format. Image detail set to `low` to minimize token cost. Both OpenAI and OpenRouter support this.

- **MealService**: New service (`meal.service.ts`) for parsing, serializing, and aggregating meal entries. Storage format: `[HH:mm] Name | cal:N p:N c:N f:N` (stored as YAML string list, same pattern as thoughts). Includes AI response parser for structured `FOOD:/CALORIES:/PROTEIN:/CARBS:/FAT:` format.

- **Meal capture modal** (`meal-modal.ts`): Full modal UI with three views:
    - List view: shows existing meals, daily totals (cal/P/C/F), manual entry and image scan buttons
    - Manual entry view: form with name/cal/protein/carbs/fat fields, pre-fills from AI analysis for editing
    - Image analysis view: drag-and-drop / file picker / clipboard paste, sends to AI, shows parsed result with accept/edit options

- **Auto-create daily notes** (`daily-note-creation.service.ts`): Reads Obsidian core Daily Notes plugin config (`app.internalPlugins.getPluginById('daily-notes')`) for folder, template, and date format. Falls back to Life Tracker's `dailyNotesFolder` + `YYYY-MM-DD` format. Applies template with `{{date}}/{{time}}/{{title}}` substitution. Separate `momentFormatToDateFns` utility for format conversion.

- **Updated `findOrCreateTodaysNote()`** in `today-utils.ts`: Now supports auto-creation via the new service. Added `silent` option to `findTodaysNote()`.

- **Three new commands**: `log-meal` (active file), `today-meal` (auto-find/create today's note), `scan-food` (AI image shortcut)

- **New settings**: `mealsPropertyName` (default: `meals`), `nutritionPropertyPrefix` (default: `nutrition`), `autoCreateDailyNote` (default: `true`), `mealAnalysisPrompt` (custom prompt override)

- **Aggregated nutrition properties**: After each meal add/remove, `{prefix}_calories`, `{prefix}_protein`, `{prefix}_carbs`, `{prefix}_fat` are recalculated and written as numeric frontmatter properties. These work with all existing Life Tracker visualizations.

- **CSS styles**: Full responsive meal modal styling following the same patterns as thoughts modal.

- **Tests**: 8 new test cases for MealService (parse, serialize, aggregate, parseAIResponse, loadFromFrontmatter, currentTime) and 8 for momentFormatToDateFns. All 999 tests pass.

### Key Decisions

- Meals stored as string list in frontmatter (same as thoughts) for Obsidian-native compatibility
- AI vision uses existing provider config -- no separate API key needed
- Core Daily Notes plugin settings read via undocumented `app.internalPlugins` API (with fallback)
- Image detail `low` for cost-effective food recognition (~85 tokens per image)
- Structured text format for AI responses (not JSON) to keep it simple and token-efficient
